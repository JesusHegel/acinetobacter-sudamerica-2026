# Archivo

Material generado durante el desarrollo del trabajo que no forma parte del
análisis publicado. Se conserva por trazabilidad: documenta cómo se llegó a
los resultados, qué se comprobó y qué se descartó.

**Nada de lo que hay aquí es necesario para reproducir el análisis.** El
procedimiento completo está en `pipeline/`, y el orden de ejecución en
`EJECUTAR.md`.

| Carpeta | Contenido |
|---|---|
| `auditoria/` | Verificaciones de consistencia realizadas durante el trabajo |
| `analisis_descartado/` | Análisis completados que no se incluyeron en el manuscrito |
| `versiones_previas/` | Scripts reemplazados por versiones posteriores |
| `deposito/` | Preparación del envío de los ensamblados propios a GenBank |
